# Daylist — Todo app

A vanilla HTML/CSS/JavaScript todo app with add, complete, delete, filters, clear completed, sticky-note styling, dark mode, and browser localStorage persistence.

## Run in Replit
Create an HTML/CSS/JS project and paste `index.html`, `style.css` and `script.js` into matching files. Run the app and open the preview.

## Run in VS Code
Open `index.html` with Live Server.

## Manual checks
1. Add two tasks.
2. Mark one completed, then use Active and Completed filters.
3. Refresh the page. Both tasks and their states should persist.
4. Delete one task.
5. Clear completed tasks.
6. Toggle dark mode and refresh.
7. Resize to phone width.

Storage is per browser and origin (Replit preview, deployed page, and localhost do not share task data).
